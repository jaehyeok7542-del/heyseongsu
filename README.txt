헤이성수 (가제) - 프로토타입 뼈대

[열어보는 법]
1) 압축을 풀고, 폴더를 VS Code로 열어요.
2) VS Code 확장(Extensions)에서 "Live Server"를 설치해요.
3) index.html 파일을 열고 오른쪽 아래 "Go Live"를 누르면 브라우저에서 앱이 열려요.
   (index.html을 그냥 더블클릭해도 화면은 보이지만, 폰 설치(PWA)는 서버로 열어야 작동해요.)

[발표 전 초기화] 주소 끝에 #reset 을 붙여 열면 저장된 제출 내역이 지워져요.

[파일 안내]
js/rules.js  : 광고 규격 기준표 (숫자는 초안! verify: true 표시는 조례/담당자 답변으로 확인 필요)
js/data.js   : 건물 목록(샘플) + 제출 내역 저장소
js/advertiser.js : 광고주용 화면 / js/admin.js : 구청용 화면 / js/tourist.js : 관광객용(보류)
