헤이성수 (가제) - 프로토타입 뼈대

[열어보는 법]
1) 압축을 풀고, 폴더를 VS Code로 열어요.
2) VS Code 확장(Extensions)에서 "Live Server"를 설치해요.
3) index.html 파일을 열고 오른쪽 아래 "Go Live"를 누르면 브라우저에서 앱이 열려요.
   (index.html을 그냥 더블클릭해도 화면은 보이지만, 폰 설치(PWA)는 서버로 열어야 작동해요.)

[발표 전 초기화] 주소 끝에 #reset 을 붙여 열면 저장된 제출 내역이 지워져요.

[파일 안내]
js/rules.js  : 광고 규격 기준표 (숫자는 초안! verify: true 표시는 조례/담당자 답변으로 확인 필요)
js/data.js   : 건물 목록(샘플) + 제출 내역 저장소
js/advertiser.js : 광고주용 화면 / js/admin.js : 구청용 화면 / js/tourist.js : 관광객용(보류)

[판단 보조 모델 (구청용)]  js/assist.js
- 구청 담당자가 승인/보류/반려를 누를 때마다 값·사진 체크·이유가 "판단 기록"으로 쌓여요.
- 새 광고가 오면 이 기록으로 다시 학습해서 (1) 비슷한 과거 사례 (2) 승인·보류·반려 가능성 (3) 그렇게 본 이유 를 보여줘요.
- 모델: 다항 로지스틱 회귀 + 최근접 이웃. 브라우저 안에서 학습해요 (서버·AI 키 불필요).
- 기록이 10건 이상, 두 가지 이상의 판단이 모이면 가능성(%)을 보여줘요.
- 구청 화면 오른쪽 위 "📊 판단 보조 모델"에서: 정확도, 영향 큰 재료, 점점 맞아지는지 그래프, CSV/JSON 내려받기.
- "시연용 가상 사례 넣기"는 진짜 구청 판단이 아니에요. 실제 분석 전에 꼭 "가상 사례 지우기"를 누르세요.
- 기록은 그 기기(브라우저)에만 저장돼요. 여러 기기 기록은 JSON 백업 → 불러오기로 합쳐요.
